Legend Of Silent Advanture is a simple text-based RPG game for command 
line interface. This game is forked version of LoS (Legend of Silence) 
that was originally developed by TheDizzler (tgillon.music@gmail.com) 
and wono (wono@live.com) as their pilot version.


How To Play 
=========== 
During the play, the program will show you messages prompting when 
events occurs. Here are brief information for commands.

1.  Moving
    You have four directions to move each room unless there is no 
    obstacles.
    *   'N' - North
    *   'S' - South
    *   'E' - East    
    *   'W' - West

2.  Using Skill
    You will have various skills while playing games. Here are some, 
    and others will be introduced later.
    
    *   'A' - Physical attack
    *   'R' - Run
